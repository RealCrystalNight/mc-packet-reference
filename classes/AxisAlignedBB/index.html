AxisAlignedBB

Immutable collision box: offsets, expansion, axis sweep resolvers and ray intercept used by moveEntity.

Deep Analysis

Immutable double collision box in net.minecraft.util with min/max corners. Used by Entity.moveEntity for collision clipping and ray traces. Matters for movement because server validates player positions against contracted and offset boxes.

Key Methods (8)

addCoord

Sweeps box along motion vector for collision broadphase.

If x<0 minX+=x else maxX+=x, same for y,z. Returns new box. Predicts occupied volume before axis-separated clipping.

expand

Grows box symmetrically on all sides.

min-=x and max+=x per axis. Negative input shrinks. Used for entity search radii and render culling inflation.

contract

Shrinks box symmetrically for stuck checks.

min+=x and max-=x per axis. Used to test sneaking and suffocation with smaller footprint. Returns new box.

calculateXOffset

Clips X motion against this box if YZ overlap.

Requires other.maxY>minY etc. If offsetX>0 uses minX-other.maxX, if <0 uses maxX-other.minX. Keeps closer-to-zero value.

calculateYOffset

Clips Y motion, handles landing and ceilings.

Same pattern on XZ overlap. Positive uses minY-other.maxY, negative uses maxY-other.minY. Core of gravity and step logic.

calculateZOffset

Clips Z motion if XY overlap.

Mirrors X/Y logic on Z axis. Prevents tunneling through walls. Chained with X and Y passes in moveEntity.

intersectsWith

Tests strict overlap on all three axes.

Uses > and < so touching faces do not count. Short-circuit ternary chain. Used for entity-entity and block push checks.

calculateIntercept

Ray-traces segment against six box planes.

Computes intermediate points per face, discards via isVecInYZ/XZ/XY, picks nearest by squareDistanceTo. Returns MovingObjectPosition with EnumFacing.
