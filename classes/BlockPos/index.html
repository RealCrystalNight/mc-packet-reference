BlockPos

Immutable integer position with MutableBlockPos for hot loops, packing, offsets and box iteration.

Deep Analysis

Immutable integer position extending Vec3i in net.minecraft.util. Created from entities, Vec3, and packet longs. Matters for packets because block dig, place, and change packets carry it as a single packed long.

Key Methods (8)

toLong

Packs x,y,z into one 64-bit long for wire.

Layout X 26 bits shifted X_SHIFT, Y 12 bits shifted Y_SHIFT, Z 26 bits. Masks with X_MASK/Y_MASK/Z_MASK. Written by PacketBuffer.writeBlockPos.

fromLong

Unpacks long back into signed x,y,z.

Sign-extending shifts: (serialized<<(64-shift-bits))>>(64-bits). Reconstructs negative coords correctly. Read path for block packets.

offset

Returns pos shifted n blocks along EnumFacing.

Adds facing offsets times n to x,y,z. Returns this if n==0. Basis for up/down/north/south/east/west helpers.

add

Adds int, double, or Vec3i delta returning new pos.

Returns this if delta is zero to avoid allocation. Double variant floors via Vec3i. Used for movement and collision stepping.

crossProduct

Computes vector cross product as BlockPos.

Formula (y1*z2-z1*y2, z1*x2-x1*z2, x1*y2-y1*x2). Used for orientation and normal math. Returns new instance.

getAllInBox

Iterates all immutable positions in cuboid.

Normalizes min/max corners. Guava AbstractIterator stepping x then y then z. Used for block scans and multi-block change.

getAllInBoxMutable

Same cuboid scan reusing one MutableBlockPos.

Avoids allocation by mutating x,y,z fields. Same x-y-z carry order. Preferred for tight collision and lighting loops.

MutableBlockPos.set

Mutates reusable pos without allocation.

Sets x,y,z fields and returns this. Overrides immutable getters to read mutable fields. Used in iteration hot paths.
