Container

GUI inventory model: Slot views, slotClick prediction, transaction IDs, shift-click merge driving C0E/S32.

Deep Analysis

Abstract server-side model for window inventories like chests, furnaces, and player inventory. Owns Slot list, item-stack snapshots, drag state, and ICrafting listeners. Implements full click/drag/shift-click/number-key/drop logic in slotClick. Change detection fans out via detectAndSendChanges.

Key Methods (8)

slotClick

Implements all window click modes 0-6 including drag-split.

Handles pickup/place, shift transfer, hotbar swap, creative clone, drop, and double-click merge. Mode 5 manages dragEvent state machine. Server calls it from C0E click processing.

detectAndSendChanges

Diffs slots against snapshots and notifies crafting listeners.

Compares each Slot stack with inventoryItemStacks via areItemStacksEqual. On change copies stack and calls ICrafting.sendSlotContents. Drives S2F and S30 updates.

transferStackInSlot

Shift-click quick-move hook overridden by subclasses.

Base returns slot stack; subclasses implement mergeItemStack ranges. Result determines what server sends back to client window.

mergeItemStack

Merges stack into slot range respecting stackability and limits.

First pass stacks onto same item/tag, second pass fills empty slots. Honors max stack size and direction flag. Core of shift-click behavior.

onCraftGuiOpened

Registers a viewer and syncs full inventory initially.

Adds ICrafting listener, calls updateCraftingInventory with getInventory, then detectAndSendChanges. Maps to S2D open plus S30 bulk.

onContainerClosed

Drops held cursor stack when window closes.

If InventoryPlayer cursor stack non-null, drops via dropPlayerItemWithRandomChoice and clears. Prevents item duplication on close.

getNextTransactionID

Allocates short action number for click confirmations.

Increments transactionID counter. NetHandlerPlayServer echoes it in S32 confirm; client C0F uses it for resync.

canInteractWith

Abstract distance/validity check for open window.

Subclasses check block distance or entity liveness. EntityPlayer.onUpdate closes screen when false. Triggers S2E close.
