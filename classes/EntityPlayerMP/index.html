Deep Analysis

Server-side player entity (extends EntityPlayer, implements ICrafting). Authoritative inventory, health, chunks, effects. Tick flow: onUpdate (block removal, container sync, destroy cache S13, chunk queue S21/S26) + onUpdateEntity (maps, S06 health, S1F XP). Owned by NetHandlerPlayServer + ItemInWorldManager.

Syncs maps, health/food, scoreboard, XP, biome achievement.

It first calls super.onUpdate for base entity aging and then scans the entire inventory for ItemStacks whose item isMap, calling createMapDataPacket for each held map and sending any non-null result directly. It compares live getHealth, foodStats.getFoodLevel and saturation-zero versus cached lastHealth, lastFoodLevel and wasHungry, sending S06PacketUpdateHealth only on a real delta to throttle health traffic. It separately tracks combinedHealth as health plus absorption for scoreboard health objectives without spamming S06. It compares experienceTotal to lastExperience and on change sends S1FPacketSetExperience with experience, experienceTotal and experienceLevel progress. Every 20 times 5 ticks it checks exploreAllBiomes progress, which can later trigger achievements without extra packets here.
