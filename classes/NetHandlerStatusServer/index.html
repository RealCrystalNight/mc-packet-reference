NetHandlerStatusServer

Server status responder: answers C00 query with S00 JSON and C01 ping with S01 echo, then closes the channel.

net/minecraft/server/network/NetHandlerStatusServer.java

Packets Referenced (2)

S00PacketServerInfoS01PacketPong

Deep Analysis

Server-side STATUS connection handler active between handshake and login. Answers a single server-list query with cached ServerStatusResponse and echoes one ping packet. Enforces one-query-per-connection then closes channel.

Key Methods (4)

NetHandlerStatusServer

Bind handler to server and connection

Stores MinecraftServer reference for status response and NetworkManager used to send replies and close channel.

processServerQuery

Reply to status query with server info

First C00PacketServerQuery sets handled and sends S00PacketServerInfo; duplicate queries close channel as already handled.

C00PacketServerQueryS00PacketServerInfo
processPing

Echo ping time and terminate status session

Replies with S01PacketPong carrying client time, then closes channel with status-handled exit message.

C01PacketPingS01PacketPong
onDisconnect

No-op disconnect hook for status phase

Intentionally empty because status connections carry no player state requiring cleanup.
