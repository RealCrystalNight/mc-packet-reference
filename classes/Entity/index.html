Deep Analysis

Base class for all world objects with position, motion, bounding box, and DataWatcher flags. Implements collision-resolved moveEntity, portal/fire/water ticks, riding, NBT save/load, and eye/look ray helpers. Server tracks pos/motion for spawn and delta packets; client interpolates via setPositionAndRotation2.

Key Methods (8)

moveEntity

Collision-resolves displacement and updates onGround and flags.

Queries World.getCollidingBoundingBoxes per axis, applies step-up logic, sneak edge handling, and fall callbacks. Sets motion to zero on impact. Basis for S14/S18 movement.

onEntityUpdate

Per-tick base logic for portal, fire, lava, and flags.

Handles portal countdown and travelToDimension, fire decay and damage, lava ignition, void kill, and DataWatcher burning flag sync. Calls water and sprint particles.

setPosition

Sets pos and rebuilds AABB from width/height.

Centers box on x/z with full height. Used by spawn, teleport, and NBT load. Does not perform collision checks.

rayTrace

Eye-to-look block raycast for interaction reach.

Builds eye pos and look vector then calls World.rayTraceBlocks with returnLastUncollidable true. Used for block targeting.

writeToNBT

Serializes pos, motion, rotation, fire, UUID, and rider.

Writes Pos/Motion/Rotation lists plus Dimension, CustomName, Silent, and nested Riding tag. Calls abstract writeEntityToNBT. Basis for chunk save.

readFromNBT

Restores entity state and re-establishes bounding box.

Clamps motion, restores pos/rotation, UUID variants, name visibility, and silent flag. Calls readEntityFromNBT then repositions. Used on chunk load.

mountEntity

Attaches or detaches rider/vehicle links.

Clears deltas, breaks old riddenBy links, prevents cycles, sets ridingEntity/riddenByEntity pair. Server broadcasts via S1B attach.

getFlag/setFlag

Packs burning/sneak/ride/sprint/eat/invisible into DataWatcher byte 0.

Bit operations on index 0; isBurning, isSneaking, isSprinting read through it. Watched index 0 syncs via S1C metadata.
