WorldManager

Server world listener: relays S25 break progress, S28 effects and S29 sounds to players near the event.

Deep Analysis

IWorldAccess bridge between WorldServer events and ServerConfigurationManager broadcasts. Applies volume-scaled and fixed radii with dimension gating. Forwards block updates to PlayerManager chunk map. Manages entity tracker add/remove.

Key Methods (8)

playSound

Broadcast named sound with volume-scaled range.

Uses sendToAllNear with radius 16.0D, or 16.0F*volume if volume>1.0F. Gated by theWorldServer dimension ID. Creates S29PacketSoundEffect with pos, volume, pitch.

S29
playSoundToNearExcept

Broadcast sound excluding one player.

Same radius rule as playSound: 16.0D or 16*volume. Calls sendToAllNearExcept for originator exclusion. Dimension-gated. Used for player-caused sounds.

S29
playAuxSFX

Broadcast block auxiliary effect near position except actor.

Calls sendToAllNearExcept with fixed 64.0D radius and dimension gate. Sends S28PacketEffect with sfxType, BlockPos, data, false. Excludes triggering player.

S28
broadcastSound

Global broadcast of auxiliary effect to all players.

Calls sendPacketToAllPlayers with S28PacketEffect soundID, pos, data, true. No distance or dimension gating. Used for portal, wither spawn style events.

S28
sendBlockBreakProgress

Send crack animation to viewers within 32 blocks.

Iterates configuration manager player list, filters worldObj==theWorldServer and ID!=breakerId. Checks d2<1024.0D (32 blocks). Sends S25PacketBlockBreakAnim directly.

S25
markBlockForUpdate

Queue chunk block change for batched send.

Delegates to PlayerManager.markBlockForUpdate mapping BlockPos to chunk. No immediate packet; PlayerInstance.onUpdate later picks S23/S22/S21 by count. Chunk-scoped fan-out.

S23S22S21
onEntityAdded

Register new entity with tracker for visibility.

Calls theWorldServer.getEntityTracker.trackEntity. Tracker later emits spawn packets per type. No direct packet here. Entry point for entity spawn fan-out.

onEntityRemoved

Untrack entity and clear scoreboard state.

Calls EntityTracker.untrackEntity then Scoreboard.func_181140_a. Causes destroy packets via tracker. No radius; removes from all viewers.
