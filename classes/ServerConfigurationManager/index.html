Deep Analysis

Server-wide player roster, bans, whitelist and spawn lifecycle. Creates NetHandlerPlayServer on login, sends join burst, and handles respawn, dimension transfer and logout broadcast.

initializeConnectionToPlayer

Sends login burst and places player.

initializeConnectionToPlayer builds the login burst for a new EntityPlayerMP after NBT load. It resolves the profile name, caches the profile, reads player NBT, binds world and ItemInWorldManager, and logs IP with entityId and coordinates. It sets game type, creates NetHandlerPlayServer and sends S01 JoinGame with entityId, game type, hardcore, dimension, difficulty, max players, terrain and reduced debug. It then sends MC|Brand S3F, S41 difficulty, S05 spawn, S39 abilities and S09 held change. It pushes stats, achievements and full scoreboard, broadcasts the join message and registers the player in the roster. It teleports with setPlayerLocation S08, syncs time and weather, applies resource pack and re-sends potion effects with S1D. Riding NBT is restored by spawning the mount entity.

allowUserToConnect

Ban, whitelist, IP and full gates.

allowUserToConnect enforces login gates in fixed order and returns a kick reason or null. First it checks profile bans via bannedPlayers, appending ban reason and formatted expiry date if present. Second it checks whitelist via canJoin, returning not white-listed when enforced and the player is neither op nor listed. Third it checks IP bans via bannedIPs with reason and expiry formatting. Fourth it checks capacity where list size at or above maxPlayers and no bypass returns server is full. Null means all gates passed and NetHandlerLoginServer may proceed to compression and LoginSuccess. The order matters because bans outrank whitelist and capacity. No packets are sent here, the caller closes with S00 using the returned string.

recreatePlayerEntity

Respawns player preserving connection.

recreatePlayerEntity respawns a dead player while reusing the NetHandlerPlayServer connection. It untracks the old entity from tracker and player manager, removes it dangerously and drops it from the roster. It copies dimension, creates a fresh ItemInWorldManager and EntityPlayerMP, then reuses the handler, clones inventory and stats, and preserves entityId and command stats. It resolves bed spawn via getBedSpawnLocation and places at plus 0.5 plus 0.1 offsets, or sends S2B state zero when the bed is invalid. It loads the chunk, lifts the player above collision up to Y 256, sends S07 Respawn, S08 location via setPlayerLocation, S05 spawn and S1F experience. It resyncs time and weather, re-adds to manager and world, restores maps and heals. No kick occurs.

transferPlayerToDimension

Moves player across dimensions.

transferPlayerToDimension moves a live player across dimensions without dropping the connection. It records the old dimension, sets the new id and sends S07 Respawn with difficulty, terrain and game type so the client rebuilds WorldClient. It removes the player dangerously, clears isDead, scales coordinates through transferEntityToWorld with factor 8.0 between overworld and nether clamped to border, or spawn point for end. It re-registers with preparePlayer, pins position with setPlayerLocation S08, rebinds ItemInWorldManager world and resyncs time and weather. It then syncs inventory and re-sends every active S1D potion effect. No kick occurs, failure leaves the player in the new world at the portal exit.

playerLoggedIn

Joins roster and announces.

playerLoggedIn joins the roster and announces presence with S38 tab-list packets. It appends to playerEntityList and uuidToPlayerMap for lookups and duplicate detection. It broadcasts S38 ADD_PLAYER for the newcomer to all existing players via sendPacketToAllPlayers. It spawns the entity in the dimension world and registers with preparePlayer to load chunks and tracking. It then loops the full roster and sends each existing ADD_PLAYER to the newcomer so tab lists converge symmetrically. No kick or teleport occurs here, position was already set by initializeConnectionToPlayer. Duplicate logins are handled earlier by createPlayerForUser kicking the old session.

playerLoggedOut

Persists and removes player.

playerLoggedOut persists and removes a disconnecting player. It triggers leaveGameStat, writes NBT and stats via writePlayerData, and removes any ridden mount dangerously. It removes the player entity and its tracker entry, drops it from playerEntityList, and clears uuidToPlayerMap and stat files only if the mapped entry is identical. It broadcasts S38 REMOVE_PLAYER to remaining players so tab lists drop the entry. No packets go to the leaver because the channel is closing. The method is called from NetHandlerPlayServer onDisconnect after the quit message. Failure to remove from maps would leave ghost tab entries and block relogin.

    public void playerLoggedOut(EntityPlayerMP playerIn)
    {
        playerIn.triggerAchievement(StatList.leaveGameStat);
        this.writePlayerData(playerIn);
        WorldServer worldserver = playerIn.getServerForPlayer();

        if (playerIn.ridingEntity != null)
        {
            worldserver.removePlayerEntityDangerously(playerIn.ridingEntity);
            logger.debug("removing player mount");
        }

        worldserver.removeEntity(playerIn);
        worldserver.getPlayerManager().removePlayer(playerIn);
        this.playerEntityList.remove(playerIn);
        UUID uuid = playerIn.getUniqueID();
        EntityPlayerMP entityplayermp = (EntityPlayerMP)this.uuidToPlayerMap.get(uuid);

        if (entityplayermp == playerIn)
        {
            this.uuidToPlayerMap.remove(uuid);
            this.playerStatFiles.remove(uuid);
        }

        this.sendPacketToAllPlayers(new S38PacketPlayerListItem(S38PacketPlayerListItem.Action.REMOVE_PLAYER, new EntityPlayerMP[] {playerIn}));
    }

triggerAchievement plus writePlayerData flush stats and NBT before removal. The ridingEntity check removes horse, boat or pig mounts to avoid orphan vehicles. removeEntity plus removePlayer plus list removal detach tracking and roster membership. The identity check before map removal protects against deleting a newer duplicate login. The final S38 REMOVE_PLAYER broadcast tells clients to purge the tab entry.

updateTimeAndWeatherForPlayer

Syncs border, time and rain.

updateTimeAndWeatherForPlayer syncs border, clock and rain to one player after login, respawn or dimension change. It sends S44 WorldBorder INITIALIZE from the overworld border so the client enforces the same center and size. It sends S03 TimeUpdate with total time, day time and doDaylightCycle gamerule. If the target world isRaining it sends S2B state 1 to start rain, state 7 with rain strength and state 8 with thunder strength. Clear weather sends only border and time with no S2B. No kick or teleport occurs. Clients apply rain strength gradually to render particles and sky darkening.

    public void updateTimeAndWeatherForPlayer(EntityPlayerMP playerIn, WorldServer worldIn)
    {
        WorldBorder worldborder = this.mcServer.worldServers[0].getWorldBorder();
        playerIn.playerNetServerHandler.sendPacket(new S44PacketWorldBorder(worldborder, S44PacketWorldBorder.Action.INITIALIZE));
        playerIn.playerNetServerHandler.sendPacket(new S03PacketTimeUpdate(worldIn.getTotalWorldTime(), worldIn.getWorldTime(), worldIn.getGameRules().getBoolean("doDaylightCycle")));

        if (worldIn.isRaining())
        {
            playerIn.playerNetServerHandler.sendPacket(new S2BPacketChangeGameState(1, 0.0F));
            playerIn.playerNetServerHandler.sendPacket(new S2BPacketChangeGameState(7, worldIn.getRainStrength(1.0F)));
            playerIn.playerNetServerHandler.sendPacket(new S2BPacketChangeGameState(8, worldIn.getThunderStrength(1.0F)));
        }
    }

Fetching the overworld border ensures nether and end players share the same boundary. S44 INITIALIZE carries center, size and warning timers in one packet. S03PacketTimeUpdate carries total age, day time and daylight-cycle flag to drive the sun. The isRaining gate adds S2B 1, 7 and 8 for rain begin plus strength lerps. Without rain the client keeps clear skies from the earlier world load.
