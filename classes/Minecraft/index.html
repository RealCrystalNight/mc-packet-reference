Deep Analysis

Client singleton owning game loop, window, renderers, player, and world. run/runGameLoop/runTick pump scheduled tasks, input, controller, world ticks, and rendering. Holds thePlayer/theWorld, NetHandler access, GUI stack, and display management. Also bootstraps integrated server connections.

Key Methods (8)

run

Outer startup and loop guard with crash handling.

Calls startGame once, then loops runGameLoop until running false. Catches memory, reported, and unexpected throwables into crash screens.

runGameLoop

Frame driver for timer, ticks, render, and FPS limit.

Updates timer, drains scheduledTasks, runs runTick per elapsedTicks, renders via EntityRenderer, syncs display, updates debug FPS and pause state.

runTick

Client tick for input, controller, world, and GUI.

Handles mouse/keyboard, hotbar, inventory key sending C16 open-inventory, click/rightClick dispatch, joinEntityInSurroundings, world.updateEntities/tick, and sound updates.

C16
loadWorld

Swaps WorldClient and rebuilds player/render state.

Cleans NetHandler, stops integrated server if unloading, sets renderGlobal/effectRenderer world, spawns thePlayer or clears it. Called on login/logout/respawn.

launchIntegratedServer

Starts local server and connects via loopback channel.

Creates IntegratedServer, waits for loop, provides local NetworkManager client, sends C00Handshake then C00 login start. Stores myNetworkManager.

C00
addScheduledTask

Thread-safe queue for main-thread execution.

If off thread enqueues ListenableFutureTask into scheduledTasks drained in runGameLoop; if on thread runs immediately. Used by NetHandler packet handling.

getNetHandler

Accessor for client play handler via player queue.

Returns thePlayer.sendQueue if player exists else null. Used to enqueue C-packets like C16 inventory and movement.

displayGuiScreen

Closes old screen, defaults to main menu or game-over, sets resolution, toggles ingame focus and sound pause. Drives inventory and pause menus.
