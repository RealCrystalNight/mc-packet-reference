PacketBuffer

Wire-format helpers: VarInt/VarLong, BlockPos, ItemStack, NBT, chat, UUID read/write used by every packet.

Deep Analysis

Netty ByteBuf wrapper in net.minecraft.network adding Minecraft codecs. Used by every Packet readPacket and writePacket method. Matters because VarInt, strings, BlockPos, ItemStack, NBT, UUID, and chat all funnel through it.

Key Methods (8)

readVarIntFromBuffer

Reads 1-5 byte VarInt packet id and lengths.

Accumulates 7 bits per byte while high bit set. Throws if more than 5 bytes. Basis for packet framing and array/string lengths.

writeVarIntToBuffer

Writes minimal-byte VarInt encoding.

While (input&-128)!=0 writes (input&127|128) then >>>=7. Single byte fast path for values under 128 like most packet ids.

readStringFromBuffer

Reads UTF-8 string with length and content checks.

VarInt length must be <=maxLength*4 and >=0. Decodes UTF-8 then enforces char length <=maxLength. Throws DecoderException otherwise.

writeString

Writes UTF-8 string with 32767 byte cap.

Encodes via Charsets.UTF_8, throws EncoderException if >32767 bytes. Prefixes VarInt length then raw bytes. Returns this.

readBlockPos

Reads packed 8-byte block coordinate.

Calls readLong then BlockPos.fromLong. Used by block change, dig, place, sign, and tile entity packets. 26/12/26 bit split.

writeBlockPos

Writes BlockPos as single long.

Calls writeLong(pos.toLong()). Canonical encoding for all block-position fields. 8 bytes versus 12 for raw ints.

readItemStackFromBuffer

Reads item id, count, meta, and NBT.

Short id -1 means null. Otherwise byte count plus short meta, then NBT compound. Used by window, creative, and equipment packets.

readNBTTagCompoundFromBuffer

Reads possibly-null compressed NBT tag.

Peeks first byte; 0 means null. Else resets readerIndex and gunzips via CompressedStreamTools with 2MB NBTSizeTracker cap.
