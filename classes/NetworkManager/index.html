NetworkManager

Netty channel wrapper: sendPacket/dispatchPacket, MessageSerializer pipeline, per-connection state machine driver.

Deep Analysis

Netty-based transport for all Minecraft connections, extending SimpleChannelInboundHandler<Packet>. Owns the Channel, packet listener (INetHandler), and queued outbound packets with read/write locks. Handles connection-state switching, encryption, compression, and local vs TCP channels. Client and server both pump it via processReceivedPackets and sendPacket.

Key Methods (9)

channelRead0

Inbound entry point that dispatches received Packet to current INetHandler.

Checks channel open then calls processPacket(packetListener). Swallows ThreadQuickExitException used to abort handling. All play/login/status packets flow through here.

sendPacket

Queues or immediately dispatches an outbound packet.

If channel open, flushes queue then dispatchPacket; else buffers under write lock. Overload accepts Netty future listeners. Used for every serverbound and clientbound send.

dispatchPacket

Writes packet to channel, handling protocol switches and threading.

Compares EnumConnectionState from packet vs channel attr; disables auto-read on change. If on event loop writes directly, else schedules task. Adds failure listener.

flushOutboundQueue

Drains buffered packets queued before channel was open.

Takes read lock and polls outboundPacketsQueue calling dispatchPacket. Called from sendPacket and processReceivedPackets. Ensures login/handshake ordering.

processReceivedPackets

Per-tick pump for network and packet listener logic.

Flushes outbound queue, ticks packetListener if ITickable, then flushes channel. Called by client runTick and server loops.

setConnectionState

Sets protocol state attribute controlling codec routing.

Stores EnumConnectionState in channel attr and enables auto-read. Called on channelActive as HANDSHAKING and on protocol upgrade during dispatch.

createNetworkManagerAndConnect

Builds client TCP pipeline and connects to remote server.

Selects NIO or Epoll channel, installs timeout/splitter/decoder/prepender/encoder/handler. Uses CLIENTBOUND decoder and SERVERBOUND encoder.

enableEncryption

Inserts cipher codecs for encrypted session after login key exchange.

Adds decrypt before splitter and encrypt before prepender using CryptManager ciphers. Sets isEncrypted flag. Triggered after login encryption response.

setCompressionTreshold

Enables or disables Netty compression codecs dynamically.

Adds NettyCompressionDecoder/Encoder before decoder/encoder if threshold >=0, else removes them. Mirrors login compression negotiation.

directionCLIENTBOUND or SERVERBOUND expected flow for this endpoint
terminationReasonDisconnect message surfaced via getExitMessage
