Deep Analysis

Server per-entity tracker state machine. Decides spawn, delta move/look, velocity, metadata for each tick. Tick flow: updatePlayerList (range/ride/ItemFrame) -> motion branch (rel vs teleport) + head/velocity/metadata. Pushes via EntityPlayerMP.playerNetServerHandler to trackingPlayers set.

Key Methods (7)

updatePlayerList

Per-tick sync: range scan, attach, ItemFrame maps, movement branch.

Refreshes player set if moved >16 blocks. Sends S1B on ride change. Every 10 ticks syncs ItemFrame maps+metadata. On frequency/airborne/dataChanged sends rel/teleport, velocity, metadata, head look.

S1BS14S18S12S19S1C
updatePlayerEntity

Adds/removes one player from tracking set with full spawn burst.

Range+chunk+isSpectatedByPlayer gate. On add sends createSpawnPacket then metadata, NBT S49, attributes S20, velocity S12, attach S1B, equipment S04, bed S0A, effects S1D.

S1CS49S20S12S04S1D
createSpawnPacket

Factory mapping entity class to spawn packet type.

Switches Item/Player/Minecart/Boat/IAnimals/mobs, projectiles by type IDs (60 arrow,73 potion,etc), FallingBlock state ID, Painting/ItemFrame/LeashKnot with pos overrides.

S0CS0ES0FS10S11
sendMetadataToAllAssociatedPlayers

Pushes DataWatcher and attribute deltas.

If hasObjectChanged sends S1C metadata. If EntityLivingBase with non-empty attribute set sends S20 properties then clears set to avoid resend.

S1CS20
sendPacketToTrackedPlayers/func_151261_b

Fan-out helpers with self-include variant.

sendPacket loops trackingPlayers sendPacket. func_151261_b also echoes to tracked EntityPlayerMP self, used for metadata/attributes/velocityChanged.

S1CS20S12
removeFromTrackedPlayers/removeTrackedPlayerSymmetric

Stops tracking and destroys entity client-side.

Removes from trackingPlayers set and calls player.removeEntity which queues S13 destroy or immediate send for players.

S13
func_180233_c

Range + spectator visibility gate.

Compares player XZ to encodedPos/32 within trackingDistanceThreshold and isSpectatedByPlayer. Prevents sending hidden/spectator-blocked entities.
