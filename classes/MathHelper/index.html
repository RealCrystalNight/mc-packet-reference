Deep Analysis

Static math utility in net.minecraft.util used by entities, rendering, and packets. Provides sin table, floor, clamp, angle wrap, and noise helpers. Matters for packets because movement yaw/pitch, positions, and chunk math all normalize through it.

Key Methods (8)

sin

Fast sine via 65536-entry lookup table.

Index=(int)(value*10430.378)&65535 where constant is 65536/2pi. Table precomputed in static block. Used for yaw, head look, and motion vectors.

cos

Fast cosine via sine table with quarter-period offset.

Index adds 16384 (pi/2) before mask. Avoids second table. Same 2pi/65536 step resolution as sin.

floor_double

Greatest integer <= double for block coords.

Casts to int then subtracts 1 if value below cast. Handles negatives correctly unlike truncation. Basis for BlockPos from entity pos.

clamp_double

Constrains value to [min,max] range.

Ternary num<min?min:num>max?max:num. Timer uses it to clamp frame delta 0-1. Also used for health, progress, and deltas.

wrapAngleTo180_float

Normalizes yaw to [-180,180) degrees.

Applies %360 then subtracts 360 if >=180, adds if <-180. Double variant identical. Critical for S08/C03 look deltas.

func_154353_e

Ceil of absolute value for packet size math.

Returns (int)(value>=0?value:-value+1). Used for entity size and bounding computations. Avoids float rounding edge cases.

bucketInt

Floor division bucket for negative chunk coords.

Formula p<0?-((-p-1)/size)-1:p/size. Ensures -1..-16 maps to chunk -1. Used for chunk lookup from block pos.

calculateLogBaseTwo

Floor log2 via De Bruijn sequence for bit packing.

Rounds up to power of two then De Bruijn multiply 125613361>>27 lookup. Subtracts 1 if not power of two. BlockPos uses it for NUM_X_BITS.
