Deep Analysis

Abstract block/entity store and simulation hub for server and client. Provides chunk-backed block access, DDA rayTraceBlocks, AABB entity queries, collision lists, and sound/particle fan-out to IWorldAccess. Owns entity/tile tick loops, light, weather, and save metadata.

Key Methods (8)

getBlockState/setBlockState

Chunk-backed block read and flagged write path.

Validates coords, delegates to Chunk, handles light check, markBlockForUpdate for render, and neighbor/comparator updates. Flags control notify vs client sync. Basis for S22/S23.

rayTraceBlocks

DDA voxel traversal returning block hit or miss.

Steps grid up to 200 iterations honoring stopOnLiquid and bounding-box flags. Calls Block.collisionRayTrace per cell. Used by Entity.rayTrace and interaction.

getCollidingBoundingBoxes

Collects block plus entity boxes intersecting an AABB.

Iterates block range with border checks, adds block collision boxes, then nearby entity boxes. Feeds Entity.moveEntity resolution.

getEntitiesWithinAABBExcludingEntity

Chunk-scoped entity query with spectator filter.

Expands chunk range by margin, delegates to Chunk.getEntitiesWithinAABBForEntity. Powers collision, combat targeting, and sleep safety checks.

spawnEntityInWorld/removeEntity

Registers and unregisters entities with chunks and lists.

Validates chunk loaded, adds players to playerEntities, links chunk and calls onEntityAdded/Removed for render/tracker hooks. Backs S0E/S13.

updateEntities/updateEntity

Ticks weather effects, entities, and tile entities.

Handles riding consistency, NaN guards, chunk migration, dead removal, and ITickable tiles. Called each world tick before block ticks.

playSoundAtEntity/spawnParticle

Fans out audible and visual effects to world accesses.

Iterates IWorldAccess for playSound, playRecord, broadcastSound, aux SFX, and particle IDs. Server listeners convert to S29/S2A; client renders directly.

setEntityState/addBlockEvent

Hooks for entity status and block animation events.

Base World is no-op; WorldServer overrides to send S19 entity status and S24 block action to trackers. Comment notes legacy Packet 38.
