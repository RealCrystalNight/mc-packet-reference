Timer

Tick-loop clock: 20 ticks/sec, renderPartialTicks interpolation, timerSpeed for timer cheats to target.

MinecraftMathHelper

Deep Analysis

Client tick-rate driver in net.minecraft.util. Owned by Minecraft game loop, called each frame via updateTimer. Converts wall-clock delta into elapsedTicks and renderPartialTicks. Matters for movement because it bounds ticks to 10 and scales by timerSpeed.

Key Methods (6)

Timer

Constructs timer with target ticks-per-second, default 20.

Stores ticksPerSecond. Seeds lastSyncSysClock via Minecraft.getSystemTime and lastSyncHRClock via nanoTime ms. Initializes timeSyncAdjustment to 1.0.

updateTimer

Advances tick counters from wall-clock delta each frame.

Computes sysClock delta j and hrClock seconds d0. If j outside 0-1000ms resets lastHRTime. Otherwise accumulates counter for drift correction.

updateTimer#sync-adjust

Calibrates hi-res clock against system clock once per second.

When counter exceeds 1000ms computes ratio counter/(k-lastSyncHRClock). Blends into timeSyncAdjustment with 0.2 factor. Resets counter and anchor.

updateTimer#accumulate

Converts seconds delta into fractional tick progress.

Formula d2=(d0-lastHRTime)*timeSyncAdjustment. Clamps d2 to 0-1 via MathHelper. Adds d2*timerSpeed*ticksPerSecond to elapsedPartialTicks.

updateTimer#cap-ticks

Extracts whole ticks and enforces spiral-of-death cap.

elapsedTicks=(int)elapsedPartialTicks then subtracts back fractional remainder. Caps elapsedTicks at 10. Prevents huge catch-up bursts after lag.

renderPartialTicks

Exposes interpolation factor for render and movement smoothing.

Public float field set equal to elapsedPartialTicks each update. Frozen when paused to avoid jitter. Read by entity rendering and camera code.

Internal State

ticksPerSecondTarget ticks per second, 20 in vanilla
elapsedTicksWhole ticks to run this frame, capped at 10
elapsedPartialTicksFractional tick carry-over between frames
renderPartialTicksInterpolation factor for rendering
timerSpeedSpeed multiplier, 0.5 is half speed
timeSyncAdjustmentDrift correction ratio for hi-res clock
