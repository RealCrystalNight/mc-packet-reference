EnumConnectionState

Protocol registry: HANDSHAKING/STATUS/LOGIN/PLAY packet-ID maps, direction routing, compression hooks.

NetworkManagerPacketBuffer

Deep Analysis

Protocol-state enum mapping packet ids to classes per direction. States HANDSHAKING, PLAY, LOGIN, STATUS with ids -1,0,2,1. Central registry consulted by NetworkManager to instantiate and route every packet.

Key Methods (6)

registerPacket

Assigns next sequential id to packet class per direction.

Creates Guava HashBiMap per EnumPacketDirection if absent. Throws if class already registered. Id equals bimap.size() before put.

getPacketId

Looks up outbound packet id for encoder.

Inverts direction BiMap and gets class key. Used when writing packet header VarInt. Returns Integer id or null.

getPacket

Instantiates inbound packet by numeric id.

Looks up class by id then calls newInstance. Returns null if unknown id. Decoder drops or disconnects on null.

getById

Resolves protocol state from handshake nextState.

Bounds-checks against -1 to 2 then indexes STATES_BY_ID. C00Handshake carries this id. Switches pipeline state.

getFromPacket

Finds owning state for a packet instance.

Looks up STATES_BY_CLASS map keyed by class. Populated in static init. Used for validation and logging.

PLAY-init

Registers all play-state clientbound and serverbound packets.

Clientbound S00-S49 plus S14/S19 sub-ids; serverbound C00-C19 plus C03/C06 splits. Order defines 1.8.9 wire ids, e.g. S08 pos-look.
