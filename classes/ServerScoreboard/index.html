Server scoreboard: objective/team/score mutations broadcast S3B, S3C, S3D and S3E to all players.

Deep Analysis

Scoreboard subclass broadcasting all objective, score, and team mutations globally. No distance or dimension gating; uses sendPacketToAllPlayers. Tracks dirty save data for persistence. Buffers create vs remove packet lists for late joiners.
