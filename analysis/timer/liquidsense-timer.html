Analysis

Overview

Timer is a four-line world-category scaler that writes its Speed value (0.1 to 10, default 2) into mc.timer.timerSpeed on every UpdateEvent. The vanilla Timer accumulator consumes wall-clock milliseconds scaled by the speed value, so the effective game-tick rate scales linearly with the setting: the default 2 runs the client at roughly 40 ticks per second, doubling the emission rate of every serverbound stream the tick drives. onDisable restores the field to 1F, and a WorldEvent handler turns the module off whenever the client leaves a world, so the scalar cannot survive a respawn or a server transfer. The module constructs no packets; its fingerprint is entirely the accelerated ledger traffic, which is why the countering set lives in the C00 and C0F corpora.

The scalar write

The module is three handlers: onUpdate writes mc.timer.timerSpeed = speedValue.get() on every fired UpdateEvent, onDisable restores 1F when the player exists, and onWorld sets state = false when the incoming WorldEvent carries a null worldClient. UpdateEvent (Events.kt line 204) fires once per game tick, so the write is continuous, not a one-shot latch: the field is re-asserted every tick the module stays on. The Speed setting spans 0.1 to 10 with a default of 2, so the out-of-box behavior is a doubled client.

Wire reach

No packet object is constructed anywhere in the file; the scalar acts on the tick clock that drives the whole client. The vanilla Timer contract, described from stock 1.8 because the snapshot ships no net/minecraft tree, is a partial-tick accumulator scaled by timerSpeed, so the effective tick rate equals 20 times the setting: the default 2 produces about 40 C03 movement packets per second plus the accelerated C00 keepalive echoes and C0F transaction confirmations. MixinMinecraft in this client shadows fields such as rightClickDelayTimer but adds no timerSpeed hook, so the module's write reaches the vanilla field directly.

Detection profile

Windowed rate checks tolerate the transient spikes of a pulse timer but the sustained scalar is a steady doubling, which pushes the movement rate window permanently positive. Inter-delay checks measure the spacing between consecutive packets against the 50ms tick expectation and fail within a few packets of the speed-up. The module is symmetric while the checks are not: sub-1 settings (0.1 to 0.9) slow the client and pass the one-directional clock checks by design, and the onDisable restore is the only guard against a stuck field on toggle-off.
