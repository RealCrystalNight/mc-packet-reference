Analysis

Overview

Rise 6.0's Disabler is a mode-selector module: one BooleanValue per bypass, and each value instantiates a dedicated Mode class from the exploit.disabler package that contains all of that bypass's packet logic. Eighteen of the nineteen mode classes are wired to toggles (three of them reused by deprecated UI aliases); WatchdogDisabler sits in the package but is not registered by the module in this build. Modes hook the client's newevent bus through @EventLink/Listener fields and lean on global components (BadPacketsComponent, PingSpoofComponent, BlinkComponent) that normalize the packet stream for anticheats.

Architecture

The module is a thin composition root. Each BooleanValue is built with four arguments: the display name, the owning module, a default state, and a Mode instance created inline. Mode<T> is the client's per-toggle base class: when a value flips on, the mode is registered with the global EventBus and its onEnable hook runs; flipping off unregisters it. Registration is reflection-based: the bus scans the mode's declared fields for the @EventLink marker, resolves the event type from the Listener<T> generic, and sorts call sites by the marker's priority byte, so every mode in this package is pure event wiring with zero lifecycle code.

The three components the modes depend on are registered once at client startup and expose static state. BadPacketsComponent flags slot/attack/swing/block/inventory packets as they are sent and clears the flags on the next C03PacketPlayer, giving modes a cheap 'is the stream polluted' test. PingSpoofComponent and BlinkComponent both buffer packets in ConcurrentLinkedQueues and replay them on a schedule or on demand. Because the disabler modes drive these components through static calls, several toggles can cooperate without knowing about each other.

Key techniques

Modes shape the outbound stream in three ways. event.setCancelled(true) drops a packet entirely, the choice for keepalives and transactions that the client wants to starve. event.setPacket(...) swaps the payload, used to upgrade C04PacketPlayerPosition into C06PacketPlayerPosLook or to corrupt the uid of a C0FPacketConfirmTransaction. PacketUtil.sendNoEvent injects a packet through addToSendQueueUnregistered so it bypasses the mode's own listener (and every other listener), while PacketUtil.send routes it through the normal pipeline; this distinction is what lets a mode emit a packet from inside its own handler without recursing.

The sprint family (SprintDisabler, DynamicPVP, Lunar, Ghostly) shares one trick: the client's EntityPlayerSP tracks serverSprintState, the sprint state the server last heard, and vanilla only sends C0BPacketEntityAction on state changes. When a START_SPRINTING arrives while the server already believes the player is sprinting, the modes first emit a STOP_SPRINTING via sendNoEvent and clear serverSprintState, then cancel the original START. The server is left believing the player is not sprinting while the client moves at sprint speed, so sprint-speed motion is never matched to a sprint action. Movement modes rewrite or gate C03PacketPlayer itself: position jitter, forced onGround flags, grid-aligned Y snapping, rotation spoofs, and whole-packet cancellation on a tick window.

Anti-cheat targeting

The mode set maps cleanly onto the anticheat landscape of 2022: CubeCraftDisabler, VulcanDisabler, VerusCustomDisabler, UniversoCraftDisabler, MineLandKickDisabler and WatchdogDisabler target named servers or anticheats, while LunarDisabler and OmniSprintDisabler aim at Lunar Client's client-side checks, and RiseBalanceDisabler is tuned against Rise's own 'Balance' anticheat on its practice servers. The generic primitives (KeepAlive, Transaction, Sprint, Input, Vehicle, Teleport, Spectate, Abilities) are server-agnostic building blocks that combine with the components for a full bypass.

Vanilla packet facts verified against the bundled MCP sources: C0FPacketConfirmTransaction carries windowId (one byte on the wire), uid (a short) and accepted, and the server's processConfirmTransaction only marks a container craftable when the echoed uid and windowId match its expected values. C00PacketKeepAlive echoes the server's random key, and processKeepAlive folds the round-trip into the player's ping as an exponential moving average. C18PacketSpectate is only honored for spectator-mode players, and S08PacketPlayerPosLook is the server's teleport-correction packet that PingSpoofComponent delays under its 'teleport' category. The server's processPlayer rejects nothing for a single absurd position packet: the 'moved too quickly' check caps each delta by the player's known motion, which is why TeleportDisabler can jump 2000 blocks and only force a correction.

What this file does

The composition root of the entire disabler suite. Twenty-two BooleanValue fields are declared in order; fifteen of them bind a named bypass to a fresh Mode instance passed as the fourth constructor argument (cubecraft, mineLandKick, verus, vehicle, teleport, vulcan, sprint, omnisprint, universocraft, riseBalance, cancelTransactions, Abilities, input, spectate, cancelKeepAlives), and the deprecated block adds hypixelSlime, mmcReachPartial and mmcKeepSprint, which instantiate second copies of AbilitiesDisabler, TransactionDisabler and SprintDisabler rather than new implementations. The class itself contains no packet logic; it only wires values to modes, so the whole file is 87 lines while the behavior lives in the 19 classes of the disabler subpackage.

The constructor implements the UI deprecation scheme. A local boolean starts false and the loop walks getValues() in declaration order: before processing each value it applies hideIf = () -> !this.deprecated.getValue() if the flag is set, then sets the flag when the current value's name equals 'deprecated'. Because the flag is read before the assignment on every iteration, the Deprecated toggle itself is never hidden, but every value declared after it (hypixelSlime through lunar) only appears in the settings screen while the Deprecated master switch is on. The legacy rows are UI aliases, not separate implementations: Hypixel Slime runs the same abilities spoof as Abilities, MMC Partial Reach the same transaction cancellation as Cancel Transactions, and MMC Keep Sprint the same sprint-packet cancellation as Cancel Sprint Packet.

The module is annotated @Rise and @ModuleInfo with the translation keys module.combat.disabler.name (a leftover from when the module lived in the combat category) and module.exploit.disabler.description, category Category.EXPLOIT. Note that WatchdogDisabler exists in the imported wildcard package but no value instantiates it in this build, so it is an orphaned mode reachable only through its class file.
