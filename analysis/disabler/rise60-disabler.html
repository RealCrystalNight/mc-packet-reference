Analysis

Overview

Rise 6.0's Disabler is a toggle registry built on the client's module component system. The class itself contains no packet logic: each BooleanValue binds a named bypass to a component class in the exploit/disabler package (CubeCraftDisabler, VulcanDisabler, KeepAliveDisabler and friends), and those components register their own packet listeners against Rise's PACKET_ROUTER. Active toggles target CubeCraft, Mine Land, Verus, Vulcan, UniversoCraft and other anticheats, plus generic primitives: keepalive cancellation, transaction cancellation, sprint entity-action cancellation, spectate injection and forced server teleports. The constructor implements a deprecation system: every setting declared after the Deprecated toggle is hidden from the UI unless that toggle is enabled.

Architecture

The module is a thin composition root. Each bypass lives in its own class under com.alan.clients.module.impl.exploit.disabler, and the Disabler core only wires values to component instances through the BooleanValue constructor. The component pattern is Rise 6.x's standard module organization: a module declares values and components, and the client instantiates and drives both. All packet work is delegated, so the core file stays at 87 lines while the behavior is spread across 19 component classes.

Packet abstraction

Rise 6.x does not use the vanilla packet event bus that older clients (Gugustus, Tenacity 5.1) expose. Packets are wrapped in the client's own Packet abstraction and routed through PACKET_ROUTER to EventLink/Listener handlers registered by components. The disabler package confirms the shift: movement components hook C03PacketPlayer and its subclasses (C04PacketPlayerPosition, C06PacketPlayerPosLook), while dedicated components eat C00PacketKeepAlive, C0FPacketConfirmTransaction, C0BPacketEntityAction, C07PacketPlayerDigging and C08PacketPlayerBlockPlacement. Serverbound spoofs cover C13PacketPlayerAbilities, C17PacketCustomPayload and C18PacketSpectate, and UniversoCraft's state machine watches S07PacketRespawn and C02PacketUseEntity.

Deprecation system

The constructor walks getValues() in declaration order with a one-value lookahead. Once it reaches the value whose name equals 'deprecated', every later value gets hideIf = () -> !this.deprecated.getValue(), so the legacy toggles disappear from the UI unless the Deprecated master switch is on. The deprecated block reuses live components: Hypixel Slime binds the same AbilitiesDisabler as Abilities, MMC Partial Reach binds the same TransactionDisabler as Cancel Transactions, and MMC Keep Sprint binds the same SprintDisabler as Cancel Sprint Packet, so those rows are historical UI aliases, not separate implementations.
