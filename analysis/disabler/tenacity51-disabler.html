Analysis

Overview

Tenacity 5.1's Disabler is a setting-driven anticheat bypass module built around a single MultipleBoolSetting named 'Disablers' that holds 13 named toggles. Every handler iterates that setting group, filters enabled toggles, and switches on the toggle name, so behavior is driven entirely by which names are active. Three Module overrides carry the logic: onMotionEvent for tick-based buffer flushing and input spam, onPacketSendEvent for cancelling, rewriting and buffering serverbound packets, and onPacketReceiveEvent for suppressing server teleports. The modes split into Hypixel-targeted Watchdog bypasses, the MMC and Omni Sprint sprint-state desyncs, and a row of generic packet transforms that cancel, rewrite or replay C03, C0B, C0C, C0F, C00 and S08 packets.

Architecture

Disabler is a name-based state machine. All 13 bypasses live as BooleanSettings inside one MultipleBoolSetting, and each event handler iterates the group, checks isEnabled, and switches on the setting name string. Three Module overrides drive everything: onMotionEvent runs every client tick (MMC buffer flush, Watchdog Timer spike, C0C input spam), onPacketSendEvent intercepts every serverbound packet and holds the bulk of the logic, and onPacketReceiveEvent handles inbound traffic for the Silent S08 mode. Packet storage uses CopyOnWriteArrayList buffers because packets are added on the send path and flushed from the tick handler. The constructor wires the three tuning values (TPDelay, hoverHeight, onGround) to their parent toggles with addParent so they only render in the UI when the matching mode is enabled.

Packet rewriting and replay

The modes reduce to three primitives. Inline mutation edits the packet before it hits the wire: Hover replaces the y of every position-carrying C03 with the player's real posY plus hoverHeight, Spoof Ground forces the onGround flag to the On Ground setting, and Void TP subtracts 1000 from the packet y every TPDelay ticks. Type rewriting swaps the packet object inside the event: C06->C04 rebuilds a position-look as a plain C04 position, dropping yaw and pitch, while C04->C06 attaches the client's current rotationYaw and rotationPitch to a plain position. Cancel-and-replay parks cancelled packets in a buffer and releases them later through PacketUtils.sendPacketNoEvent, which sends straight through the network manager with the silent flag so a replay never re-enters the PacketSendEvent hook that cancelled it in the first place.

Anti-cheat targeting

The Hypixel modes are gated by ServerUtils.isOnHypixel, which requires the server IP to contain 'hypixel' and the client brand to start with 'Hypixel BungeeCord'. Watchdog Strafe only acts while the Speed module is enabled and fallDistance is under 1: it forces onGround true, then cancels and buffers every C03 except on ticks where ticksExisted is a multiple of 4, where the whole buffer flushes at once, so the server sees movement in bursts instead of a steady stream. Watchdog Timer cancels stationary C03s outright (those with neither the moving nor the rotating flag set) and parks C0F transactions and C00 keepalives inside a 350ms window, flushing the backlog when the window elapses, while a 700ms spike timer keeps restarting that window. MMC and Omni Sprint cancel every C0B entity action, and when a START_SPRINTING arrives while EntityPlayerSP.serverSprintState says the server still believes the player is sprinting, they inject a STOP_SPRINTING first and clear the flag, so the server permanently tracks the player as not sprinting while the client sprints freely. Silent S08 cancels the server teleport and re-sends its position as a C06 with onGround=false, confirming the coordinates without the client-side snap. Verus and C0B Cancel are blanket cancels of C0F/C00 and C0B respectively, and C0C Spam pushes a fresh zeroed C0CPacketInput every tick.

What this file does

The module's entire behavior is selected by the 13 BooleanSettings inside the 'Disablers' MultipleBoolSetting; the settings carry no logic, they are dispatch keys. onMotionEvent, onPacketSendEvent and onPacketReceiveEvent each iterate disablers.getBoolSettings(), skip disabled toggles, and switch on booleanSetting.name, so renaming a toggle silently changes what the module does. The three tuning values (TPDelay, hoverHeight, onGround) are bound to their modes in the constructor with addParent, and the module suffix reflects how many toggles are enabled.

onMotionEvent runs once per client tick. The MMC case flushes the packets buffer every 1000-1500ms via MathUtils.getRandomInRange with timer reset, so the replay cadence is randomized rather than fixed. The Watchdog Timer case resets the 350ms window timer every 700ms through spikeTimer, so the desync window keeps restarting. The C0C Spam case sends a fresh default C0CPacketInput through sendPacketNoEvent every tick; all four of its fields (strafeSpeed, forwardSpeed, jumping, sneaking) default to zero, which the server's processInput applies to the player's entity action state.

onPacketSendEvent holds most of the logic. Watchdog Strafe, gated by ServerUtils.isOnHypixel, only acts while the Speed module is enabled and fallDistance is under 1: it forces the C03 onGround flag true, then cancels and buffers every C03 except on ticks where ticksExisted is a multiple of 4, at which point the backlog flushes in a burst, staggering the movement stream Watchdog samples. Watchdog Timer cancels C03s that are neither moving (the flag C04 and C06 set) nor rotating, and while the 350ms window has not elapsed it cancels and parks every C0F transaction and C00 keepalive, flushing them when the window elapses. MMC cancels every C0B: a START_SPRINTING is preceded by an injected STOP_SPRINTING whenever EntityPlayerSP.serverSprintState is true, and the flag is cleared, so the server's sprint state can never turn on; MMC also parks C0F and C00 packets in the packets buffer for the tick handler to flush. The generic transforms then rewrite or mutate C03 traffic: C06->C04 rebuilds position-look packets as plain positions, C04->C06 reattaches the current rotation, Hover raises the packet y by hoverHeight, Spoof Ground overwrites the onGround flag, Void TP subtracts 1000 from y every TPDelay ticks, and C0B Cancel and Verus blanket-cancel C0B or C0F/C00 packets with no replay.

onPacketReceiveEvent handles one mode: Silent S08 cancels an incoming S08PacketPlayerPosLook and immediately re-sends the teleport coordinates as a C06 with onGround=false via sendPacketNoEvent, so the server's correction is confirmed without the client ever snapping to it. onWorldEvent clears the Watchdog Timer buffer and resets the timer on world change. The file also carries dead weight: isBlockUnder(), a downward collision scan over 2-block steps, is never called, and joinTimer, synced, watchdogInvPackets, s08Y, spiking and airTicks are declared but never used, leftovers from earlier iterations.

What this file does

PacketUtils is the send primitive every Disabler replay depends on. sendPacketNoEvent(Packet) calls sendPacket(packet, true), which routes through mc.getNetHandler().getNetworkManager().sendPacket(packet, silent). The silent boolean is the key: Tenacity's network layer fires PacketSendEvent for non-silent sends, so a silent send reaches the server without being offered back to the module's onPacketSendEvent handler. That is what makes the cancel-and-replay modes work: a packet cancelled from the event stream can be parked, then re-sent later without being cancelled or rewritten a second time.

The class is shared across the client. The non-silent overload sendPacket(Packet) goes through the event bus normally, and isPacketValid filters out handshake, login, status and ping packets that are not play-phase traffic. In Disabler all three flush paths (watchdogPlayerPackets, watchdogC0FC00Packets and packets) call sendPacketNoEvent, so every replay bypasses the module's own interception.

What this file does

ServerUtils.isOnHypixel() gates both Watchdog modes. It first rejects singleplayer and missing ServerData, then requires the server IP string to contain 'hypixel'. Once the player entity exists it goes further: the server's brand, read from getClientBrand and populated by the server's plugin channel, must start with 'Hypixel BungeeCord'. The check therefore rules out lookalike servers that merely have 'hypixel' in their address, so the Watchdog bypasses only engage against a genuine Hypixel proxy.

The class also holds helpers the rest of the client uses elsewhere: serverCheck matches an IP suffix, isGeniuneHypixel combines the brand check with a hosts-file redirect flag, and isInLobby scans loaded entities for Hypixel's CLICK TO PLAY NPC. None of those are used by Disabler, which only ever calls isOnHypixel.
