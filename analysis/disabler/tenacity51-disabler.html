Analysis

Overview

Tenacity 5.1's Disabler is a setting-driven anticheat bypass module. A single MultipleBoolSetting holds 13 named toggles covering Hypixel Watchdog, MMC, Verus and generic packet manipulation, and the module dispatches on the toggle name in three event handlers. The packet-send path cancels, rewrites or replays C00/C03/C0B/C0F packets per toggle, the tick handler flushes buffered packets and spams C0C input, and the receive handler eats server teleports. Constructor wiring gives Hover Height, TP Delay and On Ground a parent setting so they only render when their mode is active.

Architecture

The module is a name-based state machine. All 13 bypasses live as BooleanSettings inside one MultipleBoolSetting, and every handler iterates that list, checks each enabled setting, and switches on the setting name string. Three Module overrides drive it: onMotionEvent (tick-based flushing and C0C input spam), onPacketSendEvent (cancellation, rewriting and buffering of serverbound packets) and onPacketReceiveEvent (server teleport suppression). The three tuning values (Hover Height, TP Delay, On Ground) are wired to parent settings in the constructor so they only appear in the UI when their toggle is on.

Packet rewriting and replay

The modes reduce to three primitives. Inline mutation: Hover lifts y by hoverHeight, Spoof Ground forces the onGround flag to the On Ground setting, Void TP drops y by 1000 every TPDelay ticks. Type rewriting: C06->C04 converts a position-look into a plain position, dropping yaw and pitch, and C04->C06 re-attaches the client's current rotation. Cancel-and-replay buffering: Watchdog Timer parks C0F/C00 packets for 350ms and MMC parks them for 1000-1500ms, then flushes the buffer with PacketUtils.sendPacketNoEvent, which bypasses the event bus so the replay is not re-intercepted.

Anti-cheat targeting

The Hypixel modes are gated by ServerUtils.isOnHypixel. Watchdog Strafe forces onGround and drops every 4th C03 while the Speed module is active and fall distance is under 1. Watchdog Timer cancels stationary C03 packets outright and delays transactions and keepalives to desync Watchdog's timer accounting. MMC and Omni Sprint both spoof a STOP_SPRINTING entity action when the server still thinks the player is sprinting, then cancel the original C0B so server-side sprint state stays false. Silent S08 cancels the server teleport and re-sends the position as C06 with onGround=false, so the client never snaps to the server position.
