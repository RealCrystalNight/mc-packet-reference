Analysis

Overview

Gugustus's Disabler is a configurable packet killer and anti-cheat bypass suite. Each BooleanValue setting toggles a separate behavior: cancelling specific serverbound packets (keepalive, ping, entity action, abilities, transactions), spoofing the client brand to BLC, faking abilities for RoyalPixels, or running the HAC/AAC5 teleport spam exploits. The ping-spoof mode buffers keepalives and releases them late from a render-3D tick, and the NoFlag mode cancels S08 teleports it considers small enough to eat silently.

Architecture

A single packet-send event handler (onEventSendPacket) dispatches on packet type, with one boolean flag per bypass. State is kept in a keepalive buffer list and a 'disabling' flag that the UniversoCraft mode toggles across respawn/attack/movement events. Settings use the Gugustus BooleanValue/DoubleValue framework, which stores the value by an integer id, not the field name.

Key techniques

Ping spoofing without a timer: intercept C00 keepalives, store them with a release timestamp (now + delay + 0-200ms jitter), cancel the originals, then flush them from onEventRender3D via addToSendQueueDirect so the server sees a delayed echo and measures inflated ping. The HAC mode sends a C06 position 11 blocks below every 10 ticks; AAC5 sends an extreme y-offset (1.0E159) pair; both exploit server-side movement validation gaps. NoFlag cancels S08 teleports within 8 blocks and re-sends the position itself as C06, keeping the server's view while suppressing the client-side snap.

Anti-cheat relationship

The modes are named after the anticheats they target (HAC, AAC5, NCPTimerSemi) and the servers they were built for (RoyalPixels, UniversoCraft, Minemen). The BLC spoof rewrites the MC|Brand payload to 'blc' so server-side brand checks classify the client as Badlion. The UniversoCraft transaction-uid flip (Short.MIN_VALUE/MAX_VALUE on even/odd ticks under 350 ticks) targets a specific transaction-validation quirk on that network.
