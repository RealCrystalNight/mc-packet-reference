Overview

AutoHypixel automates the Hypixel minigame loop from chat alone: it parses S02PacketChat for the exact win/lose/die prompts and Limbo-spawn messages, then emits C01PacketChatMessage commands - the /play command for the configured Skywars or Bedwars mode after a game ends, /rejoin when spawned in Limbo, and 'gg' after a win (or a loss with Win Only off). A safety group disconnects when a staff ban is detected ('A player has been removed from your game.') by sending /l, or by flooding twenty bare '/' commands to force the Limbo server, then suppresses the resulting 'Unknown command.' spam for five seconds. The module gates itself on PlayerUtil.isOnServer("Hypixel") and hides its GUI settings otherwise.

State machine

onPacketReceive matches S02PacketChat text against exact Hypixel prompt strings. 'You won! Want to play again? Click here! ' arms both the gg timer (unless Win Only suppresses losses) and the play timer; 'You lost!...' arms only the play timer unless Win Only is off; 'You died!...' arms only the play timer. Each match resets the relevant TimeUtil and clears the sent/gg flags. onPreMotion then flushes the queued actions: when timer.hasReached(playDelay + 0-100ms random jitter) and !sent it sends the /play command built by getJoinCommand() and sets sent=true; when ggTimer.hasReached(sendDelay + jitter) and !gg it sends 'gg'. onEnable resets all four timers and flags.

Ban and velocity escape

The dcOnBan branch watches for 'A player has been removed from your game.' - Hypixel's staff-ban broadcast - resets banTimer, and disconnects via the configured method: '/l' to return to the lobby, or the Limbo method which loops 21 iterations of a bare '/' C01PacketChatMessage to force the Limbo server. For five seconds afterward, any S02PacketChat containing 'Unknown command.' is cancelled (event.setCancelled(true)) so the flood's command errors never clutter chat. A dcOnVeloCheck branch that would disconnect on a suspicious S12PacketEntityVelocity is fully commented out, with a note that it cannot account for bows, snowballs and eggs.

Server gating and command building

onUpdateAlwaysInGui hides the module unless PlayerUtil.isOnServer("Hypixel") or the world is singleplayer, and onPreMotion toggles the module off with a notification when it runs off-server. getJoinCommand() maps the play mode to Hypixel's /play targets: solo_/teams_/ranked_ prefixed Skywars modes (solo_insane, teams_normal, ranked_normal) and the Bedwars queue names bedwars_eight_one, bedwars_eight_two, bedwars_four_three, bedwars_four_four, falling back to '/l'.

How it counteracts this module

How it counteracts this module

NCP's Captcha check arms a chat gate when suspicion accumulates: the player must reply with the answer to a server-generated question, and any wrong or missing answer repeats the question and raises the violation. AutoHypixel has no awareness of the captcha - onPreMotion blindly flushes the queued /play or 'gg' on its timer regardless of what the server is asking - so once Text or Commands arms the gate, the next scheduled command becomes a guaranteed captcha failure. The module's timer-driven flushing makes it unable to pause or answer, so the gate converts the automation into a self-sustaining violation loop.
