Analysis

Overview

SingleAura is the single-target mode of Nekoware's Aura module. It picks the first in-range entity from the world list, writes aim rotations into the pre-motion update, and attacks with a swing plus C02 ATTACK one event after a real timer period expires. The autoblock packets are commented out: the C08 arm and C07 release are dead code, and the only wire presence is the C0A swing and C02 attack pair, plus one C07 release when the module disables.

Targeting

Aura's onUpdate routes to SingleAura.doUpdate when the mode is Single. CombatUtil.getTarget iterates mc.theWorld.loadedEntityList and returns the FIRST EntityLivingBase within range that is not dead, not the local player, not bot-listed and not invisible unless allowed; there is no distance sort, so target selection follows entity-list iteration order rather than nearest-first. The same utility's canBlock gates the shared Aura.isBlocking flag when a sword is held, autoblock is on and an entity sits within range plus 4.0 blocks.

Attack cycle

The cadence is a real Timer: delay(1000L / clickSpeed) with a reset() on every expiry, so the period is 1000/clickSpeed milliseconds (Click Speed default 12, range 1-20). The Timer is a static field initialized at class load, so the first delay is anchored to client startup; after enable the already-expired delay makes the first attack fire on the first event, then the steady period takes over. When the delay expires on the pre-motion event, the unblocked flag is set; the very next event (the same tick's post phase) executes the swing (swingItem, which emits C0A) and PacketUtil.sendPacket with a C02 ATTACK. The rotation writes land on the pre-motion event (e.setYaw and e.setPitch, carried by that tick's C03) plus rotationYawHead, rotationPitchHead and renderYawOffset, with RotationUtils aiming at the target's eye height halved.

Blocking is dead code

Both block packets are commented out: the C08PacketPlayerBlockPlacement arm inside the isBlocking branch and the C07 RELEASE_USE_ITEM that would precede each hit. The only live artifact is the public static unblock flag, which Aura.onDisable reads to emit a single C07 release with a hardcoded position (0.221, 0.221, 0.213) when the module turns off. During operation the server never sees a block or release, so the wire carries only the C0A/C02 pair.

How it counteracts this module

NCP's fight Reach measures the attack against the survival distance limit, 4.02 by default in this tree, with the reachMod reduce band (reduceDistance 0.8, reduceStep 0.14) that accumulates on repeat hits and silently cancels them at vl>1. The module's Range setting spans 3.0 to 6.0: attacks from beyond 4.02 exceed the limit and the ledger cancels the hit, so the module is only usable inside the default band. The check measures from the player's location including eye height against the target box, so the module's center-to-center getDistanceToEntity estimate does not save it at high range.

The entry is an honest both-sides note: the mechanism targets multi-target switch patterns, which this mode by construction never produces.

How it counteracts this module

The check builds the player's direction vector from yaw and pitch plus an extrapolated delta vector and tests whether the victim AABB (expanded by boxExpand 0.2) lies between the two rays, punishing with the check's VL accumulator when the attack direction misses. Because the module writes its aim into the pre-motion update, the server-visible C03 look matches the C02 target and the ray hits, so the check rewards while Rots is on. With Rots off the attack arrives with the player's real look, which can deviate far enough to fail the between-rays test. The check is the direction twin of the reach family and the module's honest boundary.

How it counteracts this module

Arc v2's KillAura runs a Direction branch (max-direction-angle 1.2), a NoSwing branch (max-swing-time 80ms), a Reach branch (max-reach 4.2) and a Speed ledger (max-attacks 16/s, max-attack-packets 20/s), with the attack-packet counter fed per C02 ATTACK receipt and the damage-side branches on EntityDamageByEntityEvent. The module swings before every C02, so NoSwing stays silent; its aim matches the target, so Direction stays silent; at the default 12 CPS the per-second attack count sits below 16. The genuine pressure is Reach: any Range setting above 4.2 center distance trips the max-reach branch once damage lands, so the mode is bound to the same band as NCP's 4.02.
