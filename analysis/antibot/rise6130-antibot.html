Analysis

Overview

Rise 6.1.30's AntiBot is not a mode-switch module: it registers eight independent entity-classification checks as the fourth argument of BooleanValue toggles, so each check runs only while its own toggle is on. Every check is a pure client-side observer that walks mc.theWorld.playerEntities on a motion event and writes its verdict into the shared BotManager, a HashMap keyed by the check instance that maps to ArrayLists of entity ids. TargetComponent consumes that registry when it rebuilds the KillAura target list, hard-filtering with !getBotManager().contains(entity), so the module's only observable effect on the wire is a narrowed C02 attack stream; the entity list itself is also forwarded to the Rise backend as C2SPacketFilterEntities. The checks cover display-name color codes (Funcraft), movement state, duplicate names and ids, negative entity ids, tab-list ping, visibility ticks, and a manual middle-click toggle.

Architecture

Each check is a Mode<AntiBot> instance passed as the fourth constructor argument of a BooleanValue, so flipping the toggle both stores the setting and activates the check. All eight write into Client.INSTANCE.getBotManager(): add() and remove() call TargetComponent.forceUpdate() so the aura's cached target list rebuilds on the next query, and a WorldChangeEvent listener clears the whole registry on world join. AntiBot.onDisable calls botManager.clear() outright, while each mode's own onDisable clears only the list it owns, so partially configured check sets survive mode-level toggles but never a module disable.

Bot detection heuristics

FuncraftAntiBot runs on PreUpdateEvent and treats the display name as the oracle: a name containing the section-sign color code removes the entity from the bot list, a name without one adds it, which marks every uncolored name as a bot. NPCAntiBot adds entities whose moved flag is false, the signature of a static server NPC. DuplicateNameCheck and DuplicateIDCheck stream anyMatch over playerEntities and add every participant of a duplicate display name or duplicate entity id, which can also fold in the real player when a bot copies their name. PingCheck adds tab-listed players whose NetworkPlayerInfo response time is negative, NegativeIDCheck adds players with a negative entity id, and TicksVisibleCheck adds players visible for fewer than 160 ticks, removing them again at exactly 160. MiddleClickBot is the manual override: middle-click or ctrl+attack toggles the looked-at entity in and out of the registry.

Interaction with KillAura targeting

TargetComponent.getTargets streams mc.theWorld.loadedEntityList and excludes every entity the BotManager contains before serializing the survivors into C2SPacketFilterEntities for the backend and caching the returned list for 5 seconds (forceUpdate bypasses the cache). A check that over-classifies removes a real player from every aura target list for the cache lifetime; a check that under-classifies lets a server bot into the attack stream. Because the heuristics only inspect playerEntities, mob-shaped bait never reaches them, which decides which server-side bot checks can see the module's behavior.

How it counteracts this module

Kauri's bot ledger has two buffers. Buffer A scores a C02 on a tracked entity while its fake mob cluster is present (swing decays 0.05) and flags "Attacked player without attacking bot!" past 3, the filtered-state tell; buffer B scores a C02 on the per-player mob id (swing decays 0.25) and flags "Player attacked bot" past 3. The bait is not player-shaped: EntityTrackHandler spawns three invisible size-10 magma cubes around the tracked entity plus a size-5 slime on a ray 0.4 blocks ahead of the eye, with ids in the 1.5-2e9 range, so every Rise heuristic misses it by construction, because the antibot modes only iterate playerEntities. The slime rides the aim line and is re-aimed as the player turns, so aura swings aimed at the real player clip it and buffer B accumulates, while buffer A accumulates on every real-player attack the moment the cluster exists, which puts sustained pressure on any target the module is active against.
