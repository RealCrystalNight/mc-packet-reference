Analysis

Overview

Aqua 13's Scaffold is a full block-placing module built around a single onEvent dispatcher. Every tick it runs a block search (find) that picks the best support block around the player, synchronizes the hotbar slot through the EventSycItem event so the client sends the C09 held-item change, forces the rotation through EventPreMotion (either a static 180/82 look or a calculated aim from rotationrecode2), and places through the vanilla player controller, which emits C08PacketPlayerBlockPlacement. Swings are either local (swingItem) or sent as C0APacketAnimation. Six tower modes (Cubecraft, Watchdog, UpdatedNCP, WatchdogNew, IntaveFast, VerusFast) each implement a different jump profile, and VerusFast also spams fake C08 packets. The module carries its own HUD (block count with three shader styles), a block ESP, a blacklist of non-placeable block ids, timer abuse (BMCBoost at 1.105x), Down and SameY bridging, and a LegitPlace mode that reimplements the vanilla right-click pipeline.

Architecture

Scaffold extends Module and subscribes to seven events through one onEvent(Event) method: RenderNameTags (block ESP), Tick (off-ground counter), Render2D and PostRender2D (block count HUD), SycItem (hotbar slot sync), Update (search, tower, sprint and placement), and PreMotion (rotation override). All settings are registered through Aqua.setmgr with the Hero Setting framework, and the placement result is stored in the static BlockData inner class so every method can read it without passing arguments. The BlackList inner class filters block ids so non-full blocks never get placed.

Tower and bridge modes

Six tower modes are dispatched from the update pass when the jump key is held: Cubecraft (0.42 hop every 50ms), Watchdog (0.409 jump with a damped impulse on the third air tick), UpdatedNCP (0.4196 impulse on %3==1 air ticks, with a separate moving profile), WatchdogNew (the same impulse while moving only), IntaveFast (0.405 jump damped on the fifth air tick), and VerusFast, which sends fake C08PacketPlayerBlockPlacement packets (an invalid -1,-1,-1 position and a position 1.5 blocks below the player) and rides a 0.70096 vertical boost. BMCBoost runs the client timer at 1.105x while a speed potion is active. Down mode lowers the placement level to posY - 1 while sneaking, SameY keeps the level from enable time, and sprint handling has a dedicated Intave branch.

Rotation and placement logic

find() searches the six neighbors of the block below the player, then an 8-cell ring one and two blocks out, accepting only solid blocks whose attach point is not occluded by a 10-step ray trace. getBlockSlot() picks the first hotbar slot holding a non-blacklisted ItemBlock, and EventSycItem forces that slot into the client so the held-item change (C09PacketHeldItemChange) precedes each placement. EventPreMotion overrides the outgoing rotation: Static mode sets yaw + 180 and pitch 82, Calculated mode uses rotationrecode2 (atan2 aim, sensitivity snapping, pitch clamped to 78-80, optional ReverseYaw and YawPosition tuning). Placement runs through the vanilla player controller, and the swing is either swingItem or a direct C0APacketAnimation. LegitPlace reimplements the vanilla right-click mouse pipeline with the 4-tick delay.
