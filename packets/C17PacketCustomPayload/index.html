Notes

Common vanilla channels: "MC|BEdit" (book edit), "MC|BSign" (book sign), "MC|ItemName" (anvil rename), "MC|TrSel" (trade select). Mods use their own channel names.

Deep Dive

Role in the protocol

C17 is the plugin-channel transport: a channel String plus a short-length-prefixed byte payload. Vanilla channels cover brand (MC|Brand), books (MC|BEdit, MC|BSign), anvil rename (MC|ItemName), villager trades (MC|TrSel), command blocks (MC|AdvCdm) and channel registration (REGISTER). It is the most structurally open serverbound packet, since the server hands unknown channels to plugin handlers unchanged.

Vanilla handling

processVanilla250Packet dispatches on channel: MC|BEdit and MC|BSign deserialize an ItemStack and validate its NBT (ItemWritableBook.isNBTValid / ItemEditableBook.validBookTagContents) before applying; MC|TrSel reads an int trade index against the open merchant container; MC|AdvCdm requires command blocks enabled plus permission level 2 and creative mode; MC|ItemName renames the anvil item. Unknown channels are ignored by vanilla. The client side registers MC|Brand once per connection via ClientBrandRetriever.

Why clients touch it

Five families. (1) Brand spoofing: Rise 5.99 ClientSpoofer rewrites C17 payloads per mode, and the Rise 6.x ClientSpoofer's LabyMod mode cancels and replays six LabyMod/Intave payloads. (2) Disabler payload rewriting: Rise 6.2.4 TestDisabler overwrites every C17 payload with 'eyser'. (3) Console spam: Rise 6.x ChannelConsoleSpammer floods REGISTER. (4) Crash payloads: Rise 5.99 Crasher's BEdit and Mare modes push deeply nested book NBT over MC|BEdit; Tenacity's CrasherCommand floods a fixed C17. (5) Blink: PingSpoofComponent holds C17 in its blink tuple.

Exploit surface

The brand channel is a fingerprinting surface in both directions: servers read MC|Brand and REGISTER to identify clients, and spoofers forge them. The MC|BEdit path is the crash vector because the server deserializes a full ItemStack and validates deep NBT; the nested {extra:[{...}} page strings in Rise 5.99's BEdit mode are the same family as the C0E and C10 book crashes. REGISTER flooding abuses plugin channel registries that allocate per registration. Behavioral mismatch is the anti-cheat counter: a spoofed brand that behaves unlike the real client is itself a signal.

Server-Side Handling

processVanilla250Packet: channel dispatch with per-channel validation. MC|BEdit/MC|BSign validate book NBT and throw IOException on invalid tags; MC|AdvCdm gates on command blocks enabled, permission 2 and creative; MC|ItemName renames with a length check; MC|TrSel indexes the open ContainerMerchant. Unknown channels are ignored. The packet data is a PacketBuffer, so parsing is stateful and plugin-dependent.

Protocol Analysis

String channel + short data length + bytes. The REGISTER channel carries a colon-separated channel list, which is how mods announce handlers. MC|Brand is sent exactly once per connection right after login, which is why brand spoofers tell the user to rejoin. Payloads are length-prefixed shorts, so the 32KB cap applies per payload.

Anti-Cheat Landscape

Anti-cheats do not parse C17 content; anti-exploit plugins and client-detection plugins do. Client detection reads MC|Brand and REGISTER lists and compares against known client signatures, so spoofing is a cat-and-mouse over payload bytes. Book-NBT crash payloads are detected only by patched parsers. REGISTER flooding is rate-limited by anti-spam plugins.

implementation Implementation Cases

The plugin-channel packet and the corpus's widest abuse surface: brand spoofing (Rise 5.99 ClientSpoofer, Rise 6.x LabyMod), payload rewriting (TestDisabler), REGISTER flooding (ChannelConsoleSpammer), book-NBT crash payloads (Rise 5.99 Crasher, Tenacity CrasherCommand) and blink-hold integration.

ClientSpoofer (Rise 5.99)

Rewrite the C17 brand handshake so servers fingerprint the client as Forge, Lunar, LabyMod, PvP Lounge, CheatBreaker or Geyser.

On PacketSendEvent, mutates every C17 in place: sets a new payload (writeString or raw bytes) per mode, and for Lunar also rewrites the channel to REGISTER. Requires a rejoin because MC|Brand is sent once per connection.
