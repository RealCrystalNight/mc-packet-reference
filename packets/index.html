All Packets

Every Minecraft 1.8.9 network packet, organized by protocol state and direction. Click through for fields, wire encoding, server-side handling, and real client implementation cases.

Handshaking 1 packets

C00HandshakeThe very first packet sent by the client. Initiates the connection and requests a protocol state transition.

Login → Server 2 packets

C00Login StartStarts the login process by sending the player's GameProfile (username) to the server.C01Encryption ResponseResponds to the server's encryption request with the shared secret (RSA-encrypted with the server's public key) and verify token.

Login → Client 4 packets

S00Login DisconnectKicks the client during the login phase with a JSON chat component reason message (e.g. 'You are banned', 'Server is full').S01Encryption RequestRequests the client to enable encryption by sending the server's RSA public key, a verify token (random challenge), and server ID for Mojang session auth.S02Login SuccessConfirms successful authentication. Contains the player's UUID and username. Transitions the connection state from LOGIN to PLAY.S03Enable CompressionEnables zlib compression for all subsequent packets. Sets the compression threshold — packets >= this size are compressed.

Status → Server 2 packets

C00Status RequestRequests the server's status (MOTD, player count, favicon, protocol version). Empty packet with no payload.C01PingSends a client-side timestamp for the server to echo back. The client calculates round-trip latency from the difference.

Status → Client 2 packets

S00Server StatusResponds to C00PacketServerQuery with the server's status as a JSON string (MOTD, players, version, favicon, mod info).S01PongEchoes back the exact client timestamp from C01PacketPing. The client calculates round-trip latency from the difference.

Play → Server 23 packets

C00Keep Alive (Response)Response to S00PacketKeepAlive. The client echoes back the server's keep-alive ID.C01Chat MessageSends a chat message or command from the client to the server.C02Use EntityPlayer interacts with (attacks or right-clicks) an entity.C03PlayerUpdates the player's position on the server. Has subclasses for different update types.C07Player DiggingPlayer starts/cancels/ends mining a block, or drops an item (press Q).C08Player Block PlacementPlayer places a block or uses an item. Can also be used for empty-hand interactions (e.g., pressing buttons).C09Held Item ChangePlayer changes their selected hotbar slot.C0AAnimationPlayer swings their arm (left click or server-side swing). Empty packet with no payload.C0BEntity ActionPlayer performs an action: crouch, uncrouch, sprint, stop sprint, leave bed, jump with horse, open inventory.C0CInputPlayer steers a vehicle (boat or horse). Sends sideways/forward movement, jump flag, and unmount flag.C0DClose WindowPlayer closes an inventory window (chest, crafting table, furnace, etc).C0EClick WindowPlayer clicks in an inventory window. Handles item moves: pickup, shift-click, number key swap, middle click, drop, drag init, and double-click.C0FConfirm TransactionClient confirms receipt of a S32PacketConfirmTransaction (server inventory transaction).C10Creative Inventory ActionPlayer sets the contents of a slot in creative mode. Used to spawn items or modify inventory contents directly.C11Enchant ItemPlayer selects an enchantment option in the enchanting table window. Carries window ID and button (0=top, 1=middle, 2=bottom).C12Update SignPlayer finishes editing a sign. Sends the block position and four lines of text as IChatComponents.C13Player AbilitiesPlayer toggles flying state. Only sent for the flying flag change — the server controls all other ability flags via S39PacketPlayerAbilities.C14Tab CompletePlayer presses Tab in chat to request auto-completion. Sends the partial message or command.C15Client SettingsClient sends its locale, view distance, chat mode, chat colors, difficulty preference, and cape visibility.C16Client StatusClient sends a status update: respawn after death or open inventory (to achieve).C17Custom Payload (Plugin Message)Sends a plugin channel message from client to server. Used for mod communication.C18SpectateSpectator mode player teleports to another entity or player by UUID. Only works in spectator gamemode (3).C19Resource Pack StatusClient reports the resource pack load status to the server. Sent after S48PacketResourcePackSend.

Play → Client 71 packets

S00Keep Alive (Request)Server sends a keep-alive ID that the client must echo back in C00PacketKeepAlive.S01Join GameWelcomes the player into the world. Sends entity ID, gamemode, dimension, difficulty, max players, world type, and reduced debug info.S02Chat MessageServer sends a chat message or command response to the client.S03Time UpdateSynchronizes the world time (total world age and day/night cycle time). Sent every few seconds or when time accelerates (sleeping).S04Entity EquipmentUpdates an entity's equipped item in a specific slot (main hand, armor slots).S05Spawn PositionSets the player's spawn position (where compass points and respawn occurs).S06Update HealthUpdates the player's health, food level, and saturation. Sent ~20 times per second during combat.S07RespawnSends respawn or dimension change request. The client must reload the world (clear chunks, entities) and re-sync position.S08Player Position & LookForces the player to a specific position and rotation. The client must respond with a C04/05/06.S09Held Item ChangeServer confirms the player's held item slot change (echo back of C09).S0AUse BedMakes the player lie down in a bed at the specified position.S0BAnimationBroadcasts entity animation (arm swing, damage, etc.) to nearby players.S0CSpawn PlayerSpawns another player entity in the world with UUID, position (fixed-point int × 32), rotation (byte × 256/360), held item, and metadata.S0DCollect ItemShows an item being collected (picked up) by a player entity. Plays the pickup animation.S0ESpawn ObjectSpawns a non-living entity: item drop, boat, minecart, arrow, fireball, ender pearl, armor stand, etc.S0FSpawn MobSpawns a living entity (mob/animal/monster) with entity type, position, rotation, velocity, and metadata.S10Spawn PaintingSpawns a painting entity with type, position, and facing direction.S11Spawn Experience OrbSpawns an experience orb entity with position and XP value.S12Entity VelocitySets an entity's velocity (e.g., from knockback, explosion, piston push).S13Destroy EntitiesRemoves one or more entities from the client's render list.S14EntityBase class for entity relative movement and rotation updates. Subclasses S15 (rel move), S16 (look), S17 (move+look).S18Entity TeleportTeleports an entity to an absolute position (fixed-point int × 32) and rotation.S19Entity Head LookUpdates an entity's head yaw rotation independently of body rotation.S19Entity StatusSends a status event for an entity (death sound, hurt effect, taming, wolf shaking, etc.).S1BEntity AttachAttaches an entity to another (player on horse, animal on leash, leach knot).S1CEntity MetadataUpdates an entity's DataWatcher metadata (health, skin, flags, name, etc.).S1DEntity EffectApplies a status/potion effect to an entity.S1ERemove Entity EffectRemoves a potion effect from an entity.S1FSet ExperienceUpdates the player's experience bar (level, total XP, progress).S20Entity PropertiesUpdates an entity's generic attributes (movement speed, max health, knockback resistance, etc.).S21Chunk DataSends a chunk section (16x16x16 blocks) with compressed block data, light values, and biome info.S22Multi Block ChangeUpdates multiple blocks within a single chunk. More efficient than sending many S23 packets.S23Block ChangeUpdates a single block in the world — position and new block state (combined ID+metadata).S24Block ActionTriggers a block action animation/event (chest open, piston extend, note block play, etc.).S25Block Break AnimationShows block break progress (crack stages 0-9) on a block. Sent by all players, not just the miner.S26Map Chunk BulkSends multiple chunks at once. Used for initial world load and large area updates.S27ExplosionServer notifies the client of an explosion (TNT, creeper, bed in Nether/End, etc).S28EffectPlays a sound effect or particle effect at a position (without a named sound).S29Sound EffectPlays a named sound at a world position with volume and pitch.S2AParticlesSpawns particle effects at a position with offset, speed, and count.S2BChange Game StateChanges a global game state: rain toggle, gamemode change, credits, demo messages, elder guardian effect.S2CSpawn Global EntitySpawns a global entity visible to all players (lightning bolt).S2DOpen WindowOpens an inventory GUI window (chest, crafting table, furnace, enchantment table, etc.) with window ID, type, title, and slot count.S2EClose WindowServer forces the client to close an inventory window.S2FSet SlotSets a single slot in an inventory window. Used for cursor updates, specific slot changes, and armor slot updates.S30Window ItemsSends the full contents of an inventory window — all slots at once. Used for initial container opening and rejected transaction recovery.S31Window PropertyUpdates a single property in a container (enchantment level, furnace burn time, brewing progress, etc.).S32Confirm TransactionServer confirms or rejects an inventory transaction from C0EPacketClickWindow. accepted=false causes client to revert inventory.S33Update SignUpdates a sign's text for all nearby players.S34MapsUpdates a map item's data (pixels, colors).S35Update Tile EntityUpdates NBT data for a tile entity (sign, skull, beacon, command block, etc.).S36Sign Editor OpenOpens the sign editor GUI for a specific sign position.S37StatisticsUpdates statistic values (walk distance, damage dealt, items crafted, etc.).S38Player List ItemAdds, updates, or removes entries from the tab player list. Used for player join/leave, gamemode changes, ping updates, and display name changes.S39Player AbilitiesServer updates the player's capabilities (flying, invulnerable, creative, fly speed, walk speed).S3ATab CompleteServer responds to C14PacketTabComplete with a list of matching commands/player names.S3BScoreboard ObjectiveCreates or removes a scoreboard objective (the scoreboard itself, not individual scores).S3CUpdate ScoreUpdates a single scoreboard entry (add, remove, or change score value).S3DDisplay ScoreboardSets which scoreboard objective is displayed in a position (sidebar, list, below name).S3ETeamsCreate/update/remove a scoreboard team. Manages team name, prefix/suffix, players, friendly fire, and nametag visibility.S3FCustom Payload (Plugin Message)Sends a plugin channel message from server to client. Used for mod/plugin communication.S40Disconnect (Play)Kicks the player from the server during gameplay with a JSON chat component reason message.S41Server DifficultyInforms client of the server's difficulty setting.S42Combat EventServer sends combat-related events: enter combat, end combat, entity dead with death message.S43CameraSets the player's camera to spectate a specific entity (spectator mode teleport).S44World BorderUpdates the world border (center, size, warning distance/buffer, damping).S45TitleDisplays titles/subtitles on screen with animation timing. Actions: TITLE, SUBTITLE, TIMES, CLEAR, RESET.S46Set Compression LevelChanges the compression threshold mid-game. Same as S03 but for PLAY state.S47Player List Header FooterSets text above and below the tab player list.S48Resource Pack SendSends a resource pack URL and hash. Client downloads and applies it.S49Update Entity NBTUpdates the NBT data of an entity (used for command block minecarts, spawned entities with custom NBT).
